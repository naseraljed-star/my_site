# Developer Guide

## 1. Project Overview
This project is a personal website for Naser Aljed, showcasing his profile as a Cybersecurity Student. It includes information about his interests in cybersecurity, secure coding, and CI/CD pipelines.

## 2. Language Used
The website is built using HTML and CSS.

## 3. Website Purpose
The purpose of the website is to present Naser Aljed's personal information, including his role as a Cybersecurity Student, a brief about him, and contact details. It also provides links to external resources such as Google and his GitHub profile.
